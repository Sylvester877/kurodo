# Code of Conduct

## Our standard

Kurōdo is intended to be a welcoming, respectful project for people with different skill levels and backgrounds.

Participants are expected to:

- Be respectful and constructive.
- Focus criticism on code, ideas, and behavior rather than people.
- Assume good intent and ask questions before making accusations.
- Keep discussions relevant to the project.
- Respect maintainers' time and contributor boundaries.

Unacceptable behavior includes harassment, personal attacks, discrimination, threats, deliberate disruption, spam, or sharing private information without permission.

## Enforcement

Project maintainers may remove comments, close discussions, reject contributions, or restrict participation when behavior violates this code of conduct.

For serious or sensitive concerns, contact the maintainer privately rather than opening a public issue.

## Scope

This code of conduct applies to project spaces, issue discussions, pull requests, and project-related community spaces where participants are representing Kurōdo.
