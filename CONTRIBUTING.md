# Contributing to Kurōdo

Thanks for your interest in contributing.

## Quick start

1. Fork the repository and create a feature branch.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the app locally:
   ```bash
   npm start
   ```
4. Build before opening a PR:
   ```bash
   npm run build
   ```

## Pull request guidelines

- Keep changes focused and small.
- Use clear commit messages.
- Include a short summary of what changed and why.
- Add screenshots or short recordings for UI changes.
- Link related issues when applicable.

## Code style

- Follow the existing TypeScript/React style used in the codebase.
- Prefer simple, readable code over clever abstractions.
- Do not include secrets in code, commits, or screenshots.

## Reporting bugs

Please include:

- Steps to reproduce
- Expected behavior
- Actual behavior
- OS and app version
- Screenshots/logs if available
