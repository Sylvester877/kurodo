# Security Policy

## Supported versions

Security updates are provided for the latest release line.

## Reporting a vulnerability

Please do **not** open public issues for security vulnerabilities.

Instead:

1. Open a private GitHub Security Advisory in this repository.
2. Include a clear description, reproduction steps, and impact.
3. If possible, include a minimal proof of concept.

You can expect an initial response within 72 hours.

## Disclosure process

- We will acknowledge receipt and assess severity.
- We will work on a fix and coordinate disclosure timing.
- We will credit reporters who wish to be acknowledged.
