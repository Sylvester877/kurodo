# Support

## Before opening an issue

Check the [README](./README.md), [open issues](https://github.com/Sylvester877/kurodo/issues), and [Discussions](https://github.com/Sylvester877/kurodo/discussions) first. Someone may already have the same question or workaround.

## Bug reports

For reproducible bugs, use the [bug report template](https://github.com/Sylvester877/kurodo/issues/new?template=bug_report.md).

Please include the Kurōdo version, operating system, steps to reproduce, expected behavior, actual behavior, and screenshots or logs when useful.

## Feature ideas

Use [GitHub Discussions](https://github.com/Sylvester877/kurodo/discussions) for product ideas, design feedback, questions, and broader suggestions. Focused implementation tasks can then become issues.

## Contributor help

Looking for something to work on? Start with issues labeled **good first issue** or **help wanted**.

For development setup and contribution rules, see [CONTRIBUTING.md](./CONTRIBUTING.md).

## Security

Do not post security vulnerabilities in public issues. Follow [SECURITY.md](./SECURITY.md) instead.
